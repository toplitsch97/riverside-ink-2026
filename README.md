# Riverside Ink — 2026 Redesign (Preview)

A dark, cinematic 2026 redesign of [riverside-ink.ch](https://www.riverside-ink.ch) — static HTML/CSS/JS with smooth scroll (Lenis) and scroll storytelling (GSAP). Built as a client preview.

## Pages
Home · Tattoo · Piercing · Bodymodification · Beauty · Shop · Conventions · Gallery · Kontakt · Laser · Gastro · Impressum · Datenschutz

## Run locally
```bash
python3 -m http.server 8080
# open http://localhost:8080
```

No build step required. Real content & images imported from the original site.
